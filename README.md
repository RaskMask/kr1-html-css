Контрольная работа 1:

Интерактивный многостраничный интернет-магазин оригинальной техники Apple

Cсылка на проект:

https://raskmask.github.io/kr1-html-css/


Технологии:

1. **HTML5-семантика: `<header>`, `<main>`, `<footer>`, `<section>`, `<nav>`, `<article>`.**

2. **Все классы именованы по строгим правилам Блока, Элемента и Модификатора**

3. **Кроссбраузерность и адаптивность:** Сайт одинаково ровно отображается на macOS, Windows, iOS и Android.

4. **CSS-переменные:** Вся палитра цветов вынесена в блок для удобного управления дизайном.

5. **Интерактивные элементы:** 
 Реализована рабочая **якорная ссылка** для плавного скроллинга к преимуществам.
 
Создана **форма заказа** с валидацией полей (Email, Tel) и связкой тегов через `id` + `for`.

Интегрирована интерактивная **Яндекс.Карта** через тег `<iframe>`.
